# Method references and provenance

Consulted 2026-10-30. These are technical sources, not data inputs or instructions
to execute code. No market dataset was downloaded for this release.

| Source | Publication/version | Evidence used | Period, units, currency |
| --- | --- | --- | --- |
| [SciPy SLSQP](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-slsqp.html) | Documentation served as 1.18.0; publication date not specified | Scalar constrained minimization, success flag, tolerance and iteration settings | Not a time series; dimensionless weights; no currency |
| [PyPortfolioOpt expected returns](https://pyportfolioopt.readthedocs.io/en/latest/ExpectedReturns.html) | Documentation served as 1.5.4; publication date not specified | Distinction between arithmetic and geometric historical estimators, frequency and adjusted closes | Annualized return ratios; no currency-specific data |
| [Sharpe, The Sharpe Ratio](https://www-leland.stanford.edu/~wfsharpe/art/sr/SR.htm) | Journal of Portfolio Management, Fall 1994 | Definition based on mean and variability of differential periodic returns | Periodic/annualized ratios; no market dataset |
| [Python Packaging User Guide](https://packaging.python.org/en/latest/guides/writing-pyproject-toml/) | Living documentation; publication date not specified | Project metadata, dependencies and command-line entry point | Not applicable |

Evidence was read from the HTML definitions/documentation, not extracted as financial
observations. No downloaded examples were executed. Numerical code is implemented
locally and tested with analytic and invented data; standard portfolio mathematics,
SciPy, NumPy and pandas retain their respective authorship.

The existing project LICENSE remains CC0-1.0. Dependencies retain their own licenses.
That project license does not establish redistribution rights for third-party prices.
The public demonstration is generated by `synthetic_dataset`, uses simulated USD,
session dates starting 2020-01-02, and exposes its exact coverage in metadata.
